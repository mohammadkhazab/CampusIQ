CampusIQ is a full-stack campus assistant built on Python/Django (DRF), Angular/TypeScript and PostgreSQL. Students can browse a course catalog and ask a Gemini-powered assistant two kinds of question. General questions about policies and FAQs are answered from a document set using retrieval (RAG over pgvector) with source citations. Personal questions like "what am I enrolled in" are answered by an agent that calls an authenticated backend endpoint, so user-specific data stays behind the service that owns it. The project demonstrates REST API design, JWT auth, retrieval-augmented generation, and an agent tool loop with an iteration limit.
